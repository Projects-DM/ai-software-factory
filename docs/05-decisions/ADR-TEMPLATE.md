# ADR-TEMPLATE — AI Software Factory — F0-S7 Plantilla de decisión de arquitectura

Fase: F0 — Fundaciones.
Sprint: F0-S7 — Gobernanza y decisiones.
Estado: plantilla reutilizable. No es una ADR concreta: no crear ADRs
reales en F0-S7.

Copiar esta plantilla para cada nueva ADR y completar todos los campos.
Los campos entre corchetes son guía; sustituirlos por contenido real.

```markdown
# ADR-NNN — [Title]

- Status: [PROPOSED | UNDER REVIEW | ACCEPTED | IMPLEMENTED | VALIDATED | REJECTED | SUPERSEDED | DEPRECATED]
- Date: [YYYY-MM-DD]
- Decision Maker: [quién decide según nivel de gobernanza]
- Related decisions: [IDs relacionados / supersedes / superseded by]

## Context

[ Situación que motiva la decisión. ]

## Problem

[ Problema concreto que debe resolverse. ]

## Options

[ Alternativas consideradas, con pros y contras de cada una. ]

## Decision

[ Decisión adoptada, en forma verificable. ]

## Rationale

[ Por qué esta opción y no las demás, con criterios explícitos. ]

## Consequences

[ Efectos asumidos: beneficios, costes, compromisos. ]

## Risks

[ Riesgos conocidos y su tratamiento. ]

## Evidence

[ Pruebas que sostienen la decisión: datos, pruebas, referencias. Sin
  evidencia vinculada no hay avance legítimo. ]

## Review criteria

[ Condiciones o triggers que motivarán reevaluación:
  Keep / Modify / Supersede / Deprecate. ]
```
